Cypher Reasoning Core

Graph Algorithms Exposed as Agent Tools

1. Multi-Hop Outbound Traversal 
MATCH path = (start:Account {id: $acc})-[:TRANSFERRED*1..4]->(dest:Account)
RETURN [n in nodes(path) | n.id] AS path, length(path) AS hops
2. Circular Kickback Detection 
MATCH path = (a:Account {id: $acc})-[:TRANSFERRED*2..5]->(a)
RETURN [n in nodes(path) | n.id] AS cycle, length(path) AS loop
3. Active FalkorDB Quarantine 
MATCH (a:Account) WHERE a.id IN $targets
SET a.status = 'FROZEN', a.quarantined_at = timestamp()
