Track 01: Agents That Act on Connected Data

SentinelGraph is purpose-built for the Graph Hacks Track 01 challenge. Rather than treating graphs as passive text embeddings, the autonomous agent uses FalkorDB's property graph as an active relational substrate for multi-hop reasoning, dynamic tool dispatch, and live database remediation.

Topology Over Isolation

Standalone transaction scoring misses smurfing loops and coordinated mule rings. By querying multi-hop relationship chains in FalkorDB, the agent perceives structural coordination across disparate entities.

Direct Graph Navigation

The LLM planner invokes specialized Cypher graph procedures—variable-length path traversal, cycle detection, and device/IP clustering—allowing the model to inspect live graph neighborhoods on demand.

Active Graph Remediation

When illicit rings are confirmed, the agent executes write queries against FalkorDB to freeze compromised accounts, isolate nodes, and record an immutable audit dossier with verified graph provenance.
